# World V4 asset

`world-v4-folklore-atlas.png` was generated specifically for **Mah in žerjavica** with OpenAI's built-in image generation tool on 2026-08-22.

Art direction: restrained hand-painted old-school PC RPG; Slovenian and Central European timber-and-plaster architecture; three-quarter top-down perspective; moss, weathered oak, limestone, slate and muted rust.

The atlas is an original project asset. It does not copy maps, characters, melodies or UI from referenced commercial games.
