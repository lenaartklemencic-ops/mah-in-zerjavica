# Vertical-slice visual assets

Generated with the built-in ImageGen tool for **Mah in žerjavica**.

## terrain-atlas-v1.png

Prompt summary: sixteen aligned, hand-painted top-down terrain tiles covering Slovenian meadow, packed-earth road, mossy forest floor, limestone town paving, damp cave floor and shallow water; grounded classic PC fantasy RPG palette; no objects, labels, perspective or mobile-game gloss.

## kresnikovo-buildings-v1.png

Prompt summary: six Central European medieval timber-and-stone buildings in a consistent three-quarter 2D game perspective, including merchant house, townhouse, inn, forge, civic hall and market house; aged natural materials, restrained fantasy detail, no logos or UI. Background transparency is extracted at runtime before the atlas is downsampled into gameplay sprites.
